Public API Audit

This inventory covers the loaded package exports (including aliases, types, macros and contact constants), not unused historical source files. After this documentation update, all 224 defined exported bindings have discoverable Julia documentation, including inherited alias/macro documentation. Four additional exported names have no implementation and are listed below. Docstring presence alone does not prove every behavior is correct; signatures, keyword variants, examples and component conventions were reviewed separately.

Known executable-API inconsistencies

These findings are recorded without changing executable .jl source:

InterfaceCurrent behavior / recommended path
getEigenVectorsExported but undefined; use eigenVector for eigenfields, or output=:raw from solveEigen.
nodalForce!, nodalAcceleration!Exported but undefined; no callable implementation is supplied by those names.
probe_fieldExported but undefined; use the documented Gmsh-view probe interface where appropriate.
Adv(P)Calls the internal constructor without its velocity argument; use an explicit coefficient row times Grad(P) as in the advection guide.
Energy-based material tangentThe Tensors extension and DSL Voigt orders differ. See the documented two-axis permutation under constitutive models.

gmsh is re-exported from the bundled Gmsh API; this project does not duplicate its complete external reference. Field, MPC, ε, sourceVector and ∫N_c_dΩ are aliases; their primary documentation describes their target.

Repeatable docstring check

From the repository root, run:

python3 docs/check_api_docs.py
python3 docs/check_api_docs.py --strict

The default check fails on undocumented defined exports or newly undefined exports, and reports the four known undefined exports as warnings. --strict also fails for those known undefined names. The checker loads the actual Julia module and uses Base.Docs.hasdoc, so aliases and imported macro documentation are handled by Julia. It does not edit the project, install packages or run precompile workloads. It creates a temporary script outside the repository.

The docs/README.md file in the source tree describes an isolated local build and executable-example checks without deployment or dependency changes. Existing Julia source files are restricted to docstring changes.
