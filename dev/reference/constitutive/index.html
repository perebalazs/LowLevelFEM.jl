Constitutive Models and Tensor Conversion

These utilities are shared by modern weak-form formulations, even though the energy-based implementations live in nonlinear.jl. The dedicated nonlinear assembly routines are legacy.

Isotropic linear elasticity

LowLevelFEM.ConstitutiveMatrix — Function
ConstitutiveMatrix(type::Symbol)
ConstitutiveMatrix(type::Symbol, mat::Material)
ConstitutiveMatrix(type::Symbol, E, ν)

Return the isotropic elastic constitutive matrix for the selected model.

Supported models:

  • :PlaneStress
  • :PlaneStrain
  • :Axisymmetric
  • :Solid

Engineering shear strain convention is used.

Alias

D is a shorthand alias for ConstitutiveMatrix and accepts the same arguments.

D(:Solid, mat)
D(:PlaneStress, E, ν)
source
LowLevelFEM.D — Function
D(args...)

Shorthand alias for ConstitutiveMatrix.

Accepts the same arguments and returns the same constitutive matrix.

Examples

D(:Solid, mat)
D(:PlaneStress, 210e3, 0.3)
source

The material-matrix selector is :Axisymmetric, while the predefined problem type is spelled :AxiSymmetric. The coefficient alone does not add the axisymmetric hoop strain or radial integration weight to a Cartesian DSL form.

Energy-based material response

Load Tensors explicitly for differentiation of an energy function ψ(C,p). C is the right Cauchy–Green tensor. Stress and tangent are material response fields; these functions do not run a nonlinear equilibrium iteration.

LowLevelFEM.energyMaterial — Function
energyMaterial(ψ, C::TensorField; params=NamedTuple())

Compute the constitutive response from a strain energy density function.

The function evaluates the second Piola–Kirchhoff stress tensor and the consistent material tangent matrix in a fully elementwise manner.

Arguments

  • ψ: strain energy density function of the form ψ(C,p)
  • C: right Cauchy–Green tensor field (TensorField)
  • params: named tuple containing material parameters

Material parameters may be:

  • Number
  • ScalarField

ScalarField parameters are internally converted to elementwise form if needed.

Returns

A named tuple:

(; S, D)

where:

  • S is an elementwise TensorField
  • D is a 6×6 matrix whose entries are elementwise ScalarFields

The tangent can be used in DSL expressions after matching its Voigt order to the operator. See the ordering note below.

Optional extension and conventions

Load Tensors before calling this energy-based interface. The energy function ψ(C, params) must support the tensor values and automatic differentiation provided by that extension. C is the right Cauchy–Green tensor, not a Voigt strain vector. Parameters are a named tuple of numbers or compatible ScalarFields; element/column support must match C (one-column parameters can be reused across columns). Nodal input is converted to element-wise data.

Notes

Current Tensors-extension tangent ordering:

[xx, yy, zz, yz, xz, xy]

This differs from SymGrad and tensorToVector, whose order is [xx, yy, zz, xy, yz, zx]. For a symmetric constitutive tensor, convert both tangent axes before coupling to those operators:

p = [1, 2, 3, 6, 4, 5]
D_dsl = D[p, p]

The stress field uses full column-major tensor storage and needs no such permutation. This note describes the current implementation; isotropic equal-shear examples alone do not establish anisotropic compatibility.

This function computes stress and tangent simultaneously for efficiency.

source

source
The current Tensors extension returns tangents in `[xx,yy,zz,yz,xz,xy]` order,
while `SymGrad` and `tensorToVector` use `[xx,yy,zz,xy,yz,zx]`. For a symmetric
constitutive tensor use `p=[1,2,3,6,4,5]` and `D_dsl=D[p,p]` before combining
the tangent with those operators. Full tensor stress storage needs no such
permutation. The source implementation is unchanged.

Tensor components

LowLevelFEM.tensorToMatrix — Function
tensorToMatrix(T::TensorField)

Convert a tensor field to a matrix of scalar fields.

Arguments

  • T: tensor field

Returns

A 3×3 matrix whose entries are ScalarFields corresponding to the tensor components.

Examples

M = tensorToMatrix(S)

The returned matrix can be used directly in DSL matrix-chain expressions.

source
LowLevelFEM.tensorToVector — Function
tensorToVector(T::TensorField)

Extract tensor entries in Voigt order. Symmetry is assumed by the physical interpretation, but is not checked or imposed. Shear components are copied without an engineering-strain factor of two.

Arguments

  • T: symmetric tensor field

Returns

A vector of ScalarFields in the ordering:

[xx, yy, zz, xy, yz, zx]

Examples

v = tensorToVector(S)
source

Voigt extraction does not impose symmetry or multiply shear entries by two. Use constitutive and kinematic conventions consistently, especially for anisotropic materials.
