Linear Buckling and Prestressed Natural Frequencies

This tutorial shows how the geometric stiffness generated by a static pre-load can be reused for linear buckling and prestressed modal analysis of a three-dimensional cantilever column. All matrices are assembled with the weak-form interface, without a special-purpose buckling element.

Notebook

bucklingandprestressed_modes.ipynb

The executable notebook contains the complete calculation, explanatory Markdown, a comparison with Euler's buckling load, a comparison of loaded/unloaded natural frequencies, and Gmsh mode-shape visualization.

1. Static equilibrium and initial stress

Consider a prismatic column of length L = 100 and cross-section 1 × 1, clamped at the left end and subjected to a compressive reference resultant P₀ = 1 at the right end. Linear elasticity gives

\[K\mathbf u_0 = \mathbf f_0, \qquad \boldsymbol\sigma_0 = \mathbb C : \boldsymbol\varepsilon(\mathbf u_0).\]

The stiffness matrix, distributed load and displacement field are obtained as:

using LowLevelFEM, LinearAlgebra, Arpack

structured_box_mesh(lx=100.0, n=4)  # Set n=10 for a fine mesh.
mat = Material("body", E=2e5, ν=0.3, ρ=7.85e-9)
U = Field([mat], type=:VectorField, dim=3, fieldName=:u)

K = ∫(SymGrad(U) ⋅ D(:Solid, mat) ⋅ SymGrad(U))
f = ∫(U ⋅ [-1.0, 0.0, 0.0], Γ="right")
bc = BoundaryCondition("left", ux=0, uy=0, uz=0)

u0 = solveField(Symmetric(K), f; support=[bc])
ε = (u0 ∘ ∇ + ∇ ∘ u0) / 2
I3 = unitTensor(ε)
σ0 = mat.E / (1 + mat.ν) *
    (ε + mat.ν / (1 - 2 * mat.ν) * trace(ε) * I3)

With the chosen consistent N–mm–tonne–s units, the material density is 7.85e-9 and E = 2e5.

2. Assemble the geometric stiffness

For a three-component displacement field, the initial-stress bilinear form is

\[\mathbf v^T K_G\mathbf u = \int_\Omega\sum_{i=1}^3 (\nabla v_i)^T\boldsymbol\sigma_0(\nabla u_i)\,\mathrm d\Omega.\]

Grad(U) uses component-major ordering, so its 9 × 9 coefficient is block diagonal with three identical 3 × 3 stress tensors:

\[D_G = \begin{bmatrix} \boldsymbol\sigma_0 & 0 & 0 \\ 0 & \boldsymbol\sigma_0 & 0 \\ 0 & 0 & \boldsymbol\sigma_0 \end{bmatrix}.\]

s = tensorToMatrix(σ0)
DG = Matrix{Any}(zeros(9, 9))
DG[1:3, 1:3] = s
DG[4:6, 4:6] = s
DG[7:9, 7:9] = s

Kg = ∫(Grad(U) ⋅ DG ⋅ Grad(U))

3. Linear buckling

If the actual applied load is α times the reference load, the linearized buckling equation is

\[(K+\alpha K_G)\boldsymbol\phi=0.\]

For a compressive reference stress, one convenient generalized eigenproblem is

\[K_G\boldsymbol\phi=\mu K\boldsymbol\phi, \qquad \alpha_{\mathrm{cr}}=-1/\mu.\]

buckling = solveEigen(Kg, K; support=[bc], nev=6, which=:SR)
buckling = LowLevelFEM.mapEigenValues(μ -> -1 / μ, buckling)
αcr = getEigenValues(buckling)
showEigenResults(buckling; name="Buckling modes", ff=2)

For a clamped-free beam, Euler theory predicts

\[P_\mathrm{cr,Euler} = \frac{\pi^2 EI}{4L^2}.\]

With I=1/12, E=2e5 and L=100, this is approximately 4.1123 in consistent force units. The 3D FE result converges toward this value as the mesh is refined.

4. Prestressed natural frequencies

The consistent mass matrix and the prestressed modal problem are

\[\mathbf v^T M\mathbf u = \int_\Omega \rho\,\mathbf v\cdot\mathbf u\,\mathrm d\Omega, \qquad (K+\alpha K_G)\boldsymbol\phi = \omega^2 M\boldsymbol\phi.\]

For the original reference load, α = 1. Compute modes both with and without that compressive load:

M = ∫(U ⋅ mat.ρ ⋅ U)

free_modes = solveEigen(Symmetric(K), Symmetric(M);
    support=[bc], nev=6, shift=0.0)

prestressed_modes = solveEigen(Symmetric(K + Kg), Symmetric(M);
    support=[bc], nev=6, shift=0.0)

freq_free = sqrt.(getEigenValues(free_modes)) ./ (2π)
freq_pre = sqrt.(getEigenValues(prestressed_modes)) ./ (2π)

These eigenvalues are squared angular frequencies (ω²). The conversion to hertz is f = sqrt(ω²)/(2π). For a stable column, compression lowers the first bending frequencies. Increasing the load toward the first critical factor causes the corresponding squared natural frequency to approach zero.

frequency_modes = LowLevelFEM.mapEigenValues(
    ω2 -> sqrt(ω2) / (2π), prestressed_modes)
showEigenResults(frequency_modes;
    name="Prestressed frequencies [Hz]", ff=1)

Scope and limitations

The formulation uses linear elasticity, an initial-stress geometric stiffness and a linearized tangent about the reference configuration. It predicts the onset of instability and the effect of pre-load on small vibrations; it does not simulate post-buckling deformation or nonlinear equilibrium evolution.
